### 📌 About Project
This is a DevOps project to show automated website deployment.
Inspired by dealsbe.com design.
When we push code to GitHub, it automatically goes LIVE in 30 seconds using GitHub Actions.

### ⚙️ How it Works
1. Code Push to GitHub
2. GitHub Actions Build Starts
3. Website Deploys to GitHub Pages
4. LIVE in Chrome

### 🛠️ Tech Used
- HTML, CSS
- GitHub Actions (CI/CD)
- GitHub Pages (Hosting)
